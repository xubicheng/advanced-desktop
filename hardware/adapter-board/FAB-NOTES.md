## 二、装配说明（如果一并报 PCBA）

- **SMT 仅 3 个位号 / 5 只器件**：C2（100nF 0805）、R1（1k 0805）、LED1（绿色 0805）。
- 其余全部为**通孔件，建议手工焊**：J1 DC 座、F1 保险丝座、D1 SS54（SMA）、D2 SMAJ5.0A（SMB）、C1 470µF（D8/P3.5）、J2–J4 JST XH 2P、SW1 6×6 按键、J6 2.54 排针。
- 极性/方向必须核对：
  - **D1 SS54**：丝印竖线端为阴极（K），阴极朝 **+5V** 侧（防反接）。
  - **D2 SMAJ5.0A**：单向 TVS，阴极（色带）朝 **+5V**，阳极接 GND。**方向接反等于把 5V 短路到地。**
  - **C1 470µF**：电解，长脚 +，丝印 "+" 在靠板内一侧；**成品高度 ≤ 12 mm**。
  - **J1**：中心正极（5.5×2.1）。
  - **J2/J3/J4**：JST XH 2P，1 脚 = +5V，2 脚 = GND，三路分别给 BBB / USB Hub / 功放。
  - **SW1**：一脚接 PTT，另一脚接 GND；按下短接到地（低有效）。
- 丝印文字 "AD Carrier-Lite v0.1 DRAFT" 为草案标识，投产版会改。

## 三、功能与网络（无原理图，以网表为准）

| 网络 | 连接 |
|---|---|
| 5V_IN | J1.1 → F1.1 |
| FUSED | F1.2 → D1 阳极 |
| +5V | D1 阴极 → D2 阴极、C1+、C2、R1、J2/J3/J4 的 1 脚 |
| GND | J1.2/1.3、D2 阳极、C1−、C2、LED1 阴极、J2/J3/J4 的 2 脚、SW1.2、J6.2 |
| LED_A | R1.2 → LED1 阳极（电源指示） |
| PTT | SW1.1 → J6.1（接 BBB GPIO） |

链路：**DC 5.5×2.1 输入 → 3 A 慢断保险丝 → SS54 防反接 → SMAJ5.0A 过压钳位 → 470µF + 100nF 滤波 → 5V 三路分配**。

> 注意：本交付**只有 PCB + BOM + 网表**，未出原理图（.kicad_sch）。评审以 .kicad_pcb + 本文件网表为准。

## 四、需要整合商评估的两点

1. **SS54 串联压降**：2 A 时约 0.45–0.55 V，5.0 V 输入到负载只剩 4.45–4.55 V，BBB 满载可能欠压。
   建议评估：换 **PMEG4050 / MBRS540** 等低 VF 肖特基，或把电源改为 **5.1–5.2 V / 4 A**，或改用理想二极管（LM66100 类）。
2. **连接器与结构**：J1 为卧式 DC 座，尾插方向；J2–J4 朝板右侧出线。请确认与外壳/线束方向一致后再投产。

## 五、待实测项（本版按标准封装绘制，尺寸未实测）

- 成品 USB 鼠标模块的光学高度与透镜位置；
- BBB 实际安装孔位（M2.5 或 M3）与本板 H1–H4 的对位；
- USB Hub 小板尺寸与其 5V 外供焊盘位置；
- 壳内净空能否容纳 C1（≤12 mm）与 J1。
