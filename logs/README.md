这里存放与协作方（AI 助手）沟通的**纪要**，用于留下决策痕迹。

## 脱敏规则（红线）

提交前必须删除：
- 任何口令、令牌（token）、API Key、Cookie；
- 任何私钥（`id_rsa` / `id_ed25519` / `.pem` / `.p12`）；
- 邮箱、手机号、身份证号、住址；
- 内网 IP（`10.*` / `172.16-31.*` / `192.168.*`）、内网域名、SSH 端口；
- `.env` 类文件内容。

保留：
- 需求、约束、决策、被否决的方案与理由；
- 公开可查的型号、价格区间、许可证名称。
