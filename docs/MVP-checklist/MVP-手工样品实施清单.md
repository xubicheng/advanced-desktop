# AD MVP 手工样品 · 实施清单

> 配套文档：`docs/v3/AD-鼠标形无屏微型计算机-设计方案-v3.md`（v3.0）
> 适用路线：**β = BeagleBone Black（唯一路线）**。α/γ 已作废。
> 本清单是"照着做"的执行件：**买料 → 焊 → 装 → 测 → 过**。每一步都有可测量的通过标准。
> 状态：**未采购、未下单**。所有价格为区间【询价】，所有性能为预期值【实测】。
>
> **v3 关键差异（照做前必读）：**
> 1. 分辨率 **720p**（不是 1080p）；
> 2. 供电 **DC 5.5×2.1 / 5V 4A**（不是 USB-C 5V/3A）；
> 3. 光标 **只用成品 USB 鼠标模块**，**取消 PMW3389 自研**（原 S5 整节删除）；
> 4. 外壳 **132×76×40mm 真鼠标**（不是 160×95×100 掌托式）；
> 5. 新增 **4 口自供电 USB Hub + 上游 VBUS 断路**；
> 6. 本地 STT/TTS **不做**，语音默认走云端。

## 2. S1 裸板点亮（4h）—— **全项目生死线**

| 步 | 操作 | 工时 | 通过标准 |
|---|---|---|---|
| S1.1 | 下载 **BeagleBoard 官方 Debian 镜像**，用 balenaEtcher 烧到 microSD（或直接烧 eMMC） | 0.5h | 烧写完成无报错 |
| S1.2 | 只接：**DC 5.5×2.1 5V/4A 电源** + **micro-HDMI 软排线 → 显示器** + SD 卡 | 0.5h | 板载 4 个用户灯按官方启动序列闪烁 |
| S1.3 | 用 USB-TTL 接调试串口（P9 的 UART0：GND/TX/RX），看启动日志 | 1.0h | 串口能打印到 `login:` |
| S1.4 | 等待首次启动（1–3 分钟） | 0.5h | **屏幕出现桌面 / 或串口可登录** |
| S1.5 | 设分辨率 1280×720（`xrandr --output HDMI-1 --mode 1280x720` 或 `wlr-randr`） | 0.5h | 显示 1280x720 |
| S1.6 | 连续播放 720p 视频 30 分钟 | 1.0h | **无闪屏、无花屏、无重启、无欠压告警**（`dmesg` 中查 voltage 关键字） |

**判定与止损：**
- ✅ 通过 → 进 S2。
- ❌ 无显示 → 先分三步排查：① 串口有没有启动日志（有 = 板活着，是显示问题）；② 换 micro-HDMI 转接、换显示器；③ 换镜像。3 次仍失败 → **换板**，不要试图改内核。
- ❌ 反复重启 → **90% 是电源**：先量 DC 座入口电压（≥4.90V），再查线径（≤1m、≥20AWG），最后才怀疑板。
- ❌ 串口全无输出 → 检查 USB-TTL 的 TX/RX 是否交叉、GND 是否共地。

> BBB 的 micro-HDMI 座是贴片焊，**插拔时务必扶住板子**；建议转接线一次插好就不再动。

**常见问题：**
| 现象 | 原因 | 处理 |
|---|---|---|
| 录音全是电流声 | 麦克风线太长/无屏蔽 | 换屏蔽线，缩短到 3cm |

## 5. S4 光标：内嵌成品 USB 鼠标模块（3h）

> v3 的 D3 决策：**不再自研 PMW3389 + 透镜 + 光学腔**。直接买成品 USB 鼠标模块（USB HID），插上就是鼠标。
> 原来的 S5「光标自研」整节删除；不确定性从「写驱动 + 调光学腔」变成「选模块 + 配光学高度」。

| 步 | 操作 | 工时 | 通过标准 |
|---|---|---|---|
| S4.1 | 模块插电脑验证 | 0.5h | 光标能动、左右键/滚轮正常、无丢帧 |
| S4.2 | 模块插 BBB 的 USB 口（此时还没接 Hub） | 0.5h | `lsusb` 能看到；`cat /dev/input/mouse0` 有输出 |
| S4.3 | 量 **透镜下沿到桌面的距离** | 0.5h | 记录实测值（不同模块 1.2–2.0mm 不等）【实测】 |
| S4.4 | 用 3D 打印的三种厚度垫片（0.5 / 1.0 / 1.5mm）试装，找到光标最稳的一档 | 1.0h | 慢移不飘、快移不丢、静止不漂 |
| S4.5 | 用 `xinput` 调加速度与速度（若 DPI 偏高） | 0.5h | 1080p 屏幕上从左上到右下约 3–4 次滑动 |

**熔断规则：**
> 若换 2 个不同型号的模块仍无法让光标稳定移动（飘 / 丢帧 / 完全不响应）→ **不要继续折腾**，改为「外置 USB 鼠标」过渡，把内嵌留到结构版再解决。项目不得因此停摆。

**常见问题：**
| 现象 | 原因 | 处理 |
|---|---|---|
| 光标完全不动 | 模块光学高度太高（透镜离桌面太远） | 减薄垫片，让透镜贴近桌面 |
| 慢移正常快移飘 | 光学高度偏低 / 桌面太光滑 | 加 0.5mm 垫片；换鼠标垫测试 |
| 静止时缓慢漂移 | 桌面反光 / 漏光 | 换哑光鼠标垫；模块四周遮光 |
| 光标「飞」得太快 | DPI 过高（1600+） | 用 `xinput --set-prop` 降加速度，或换 800/1000 DPI 模块 |
| 左右键没反应 | 买成了「只有传感器没有按键」的模块 | 换带完整按键的模块 |

## 7. S6 集成分线（8h，可选但推荐）

> 目的：把「DC 输入保护 + USB Hub 自供电路 + 排针 + 按键」做在一块洞洞板上，替代一堆飞线。
> 元件数控制 **≤25 个**，全部 0805/插件，纯手焊。

| 步 | 操作 | 工时 | 通过标准 |
|---|---|---|---|
| S6.1 | 洞洞板布局（先画纸上草图） | 1.0h | 元件不重叠，走线最短；**Hub 远离麦克风** |
| S6.2 | 焊 DC 5.5×2.1 座 → 3A 保险丝 → SS54（防反接）→ SMAJ5.0A → 470µF + 100nF | 2.0h | 空载输出 5.0±0.1V；**反接测试不烧**（用限流电源试） |
| S6.3 | 焊 Hub 的 5V 外供线（从系统 5V 母线取） | 1.0h | Hub 4 口供电正常，单口带载 0.5A 不掉压 |
| S6.4 | **切断 Hub 上游线的 VBUS（红线）与 ID，只留 D+/D−/GND**，断口热缩绝缘 | 1.0h | 万用表量上游 VBUS 与 Hub 5V **不导通**（>1MΩ） |
| S6.5 | 焊排针引出 5V / GND / PTT GPIO（P9 的 GPIO 口） | 1.0h | 万用表通断全通 |
| S6.6 | 焊 PTT 轻触 + 音量键 + 指示灯（各串 1kΩ 限流） | 1.0h | 按下导通、松开断开 |
| S6.7 | **上电前检查**：5V↔GND | 0.5h | **>1kΩ** |
| S6.8 | 反灌验证（V5 验收） | 0.5h | 只给 Hub 供电、不给 BBB 供电时，BBB **不得出现半上电**（指示灯不亮、串口无输出） |

### 上电检查点（每次通电前必做，5 步）

1. **目视**：无连锡、无歪件、无金属屑；
2. **通断**：二极管档量 5V↔GND，**>1kΩ**；
3. **极性**：电解电容负极、二极管方向、**DC 座中心正**；
4. **限流上电**：可调电源限流 500mA，看电流是否异常（>300mA 空载即有短路）；
5. **全电流上电**：确认正常后接主板。

| 承重 | **只能用尼龙柱 + M2.5 螺丝**，热熔胶只做辅助定位 |
| 板底 | 贴 0.5mm 青稞纸/聚酰亚胺胶带 |
| 电源线 | 20AWG 红黑双绞，走边缘，远离麦克风与光学窗 |
| 麦克风线 | 屏蔽线，屏蔽层单端接地 |
| micro-HDMI | 壳内 S 型弯 + 扎带 + 硅胶，做应力释放（**最容易拽掉**） |
| 喇叭 | 四周 1mm EVA 泡棉防共振 |
| 光学窗 | 外侧贴 0.1mm 防尘毛毡圈；**禁用胶水**（会污染透镜） |

## 9. S8 热测与整改（6h）

| 步 | 操作 | 工时 | 通过标准 |
|---|---|---|---|
| S8.1 | 25°C 环境，**锁频 800MHz**，满载（`stress-ng --cpu 1 --vm 1` + 循环 TTS + WiFi 传输） | 0.5h | 系统稳定 |
| S8.2 | 30 分钟后红外测温（**顶面手掌区 5 点**、左右侧面、底部出风口） | 0.5h | 取 5 点最高值 |
| S8.3 | 读 `/sys/class/thermal/thermal_zone0/temp` | 0.5h | — |
| S8.4 | 查降频：`cpufreq` 的 `time_in_state` 是否出现 1GHz 档 | 0.5h | **不应出现** |
| S8.5 | 判定 | 0.5h | **顶面 ≤45°C 且 SoC ≤85°C 且不降频** |
| S8.6 | 不达标 → **后备 1**：顶面靠后 1/3 开 20×40mm 细格栅（1.2mm 缝 ×8） | 2.0h | 复测降 5–8°C |
| S8.7 | 仍不达标 → **后备 2**：尾部加 5V 20mm 风扇（吸入式） | 1.5h | 复测降 12–18°C |
| S8.8 | 都不达标 → 后备 3：降频 600MHz + 关 WiFi 改有线 | 0.5h | 复测降 4–6°C，记录性能损失 |

**若三级后备都不达标**：说明「L1 板 + 鼠标形态」在散热上确实到顶，应改为开放式支架或等 T3（BeaglePlay），**不要在壳上无限加风扇**。

**开孔权衡（必须写进验收记录）：**
- 开孔率每 +1%，腔内温度约降 1.5–2.5°C，但进灰速率约 +25%；
- 底部孔会吸桌面灰尘，**约 3 个月需清一次**（拆底盖，软毛刷 + 气吹）；
- 侧面孔位于握持凹陷处，**必须倒角 0.5mm + 内侧贴 80 目网**，否则硌手；
- 顶面**不开格栅**：手掌整面贴合，开孔=手感灾难 + 烫手 + 大量进灰。只有在后备 1 才动，且只开靠后 1/3。

## 10. S9 语音链路（10h）—— **默认云端，本地不做识别**

> v3 的硬结论：单核 Cortex-A8 @1GHz 上，whisper tiny 慢 5–10 倍、sherpa-onnx 慢 3–5 倍，**本地 STT/TTS 不可用**。
> 所以本节只做：云端 STT/LLM/TTS + 本地预录提示音 + 规则引擎降级。

| 步 | 操作 | 工时 | 通过标准 |
|---|---|---|---|
| S9.1 | PTT 按键（GPIO，去抖 20ms，长按 200ms 触发）+ 录音门控 | 2.0h | 按住说、松开停；误触发 0 |
| S9.2 | 录音 16k/16bit/mono，opus 20ms 帧编码 | 2.0h | 3 秒录音文件 ≤ 12KB；解码回放无失真 |
| S9.3 | 接云端 STT（HTTPS 上传） | 1.5h | 3 句中文，字准确率 ≥ 90% |
| S9.4 | 接云端 LLM（OpenAI 兼容，SSE 流式）+ 分句缓冲 | 1.5h | 首 token ≤ 1.5s；按句切分 |
| S9.5 | 接云端 TTS（流式）→ USB 声卡 → PAM8403 播放 | 1.5h | 首音 ≤ 3.5s（端到端） |
| S9.6 | 预录提示音 6–10 条（16k WAV）+ 规则引擎（音量/暂停/静音/取消） | 1.0h | 断网时这些指令仍可用 |
| S9.7 | 降级：网络探测 → 超时 5s → 播报「服务慢」→ 断网播报「网络不通」 | 0.5h | 断网 ≤2s 给出语音反馈，**不尝试本地识别** |

> **注意**：不要用 piper —— 它依赖 espeak-ng（GPL-3.0），链接后你的程序整体变 GPL-3.0。本项目 P0 不用本地 TTS，若将来要用，选 sherpa-onnx TTS（Apache-2.0）且需先核实权重许可。

**降级三级（与 v3 方案 §3.4 一致）：**
1. 云端全通 → 正常；
2. 网络通但云服务超时（>5s 无首包）→ 播报「服务慢，先记下」，语音存本地队列；
3. 完全断网 → 预录提示音 + 规则引擎 + 屏幕「离线模式」。

## 12. 快速故障排查表

| 现象 | 优先排查 | 处理 |
|---|---|---|
| 上电无反应 | 电源、3A 保险丝、5V 短路 | 换电源；量保险丝两端通断 |
| 反复重启 | 电源电流不足、线太细、入口电压塌陷 | 换 5V/4A；线 ≥20AWG ≤1m；测满载入口 ≥4.90V |
| 无显示但有串口日志 | micro-HDMI 转接、显示器输入源 | 换软排线转接；强制 720p |
| HDMI 偶发黑屏 | 供电跌落、micro-HDMI 接触不良 | 测入口电压；线做应力消除 |
| 串口无任何输出 | USB-TTL 接线、SD 镜像 | TX/RX 交叉；GND 共地；重烧镜像 |
| USB 设备反复掉线 | Hub 供电不足 / 上游 VBUS 未断导致冲突 | Hub 自供电；**确认已切断上游 VBUS** |
| 插上 Hub 后 BBB 起不来 | 上游 VBUS 反灌 | 立刻断电，检查 S6.4 是否执行到位 |
| 录音有电流声 | 麦克风线未屏蔽/过长 | 换屏蔽线，<3cm；mic bias 单独滤波 |
| 喇叭破音 | 无音腔/增益过高 | 做密封音腔；降增益到 70% |
| 说话时啸叫 | 麦克风与喇叭太近 | 分置两端；PTT 门控（半双工） |
| 光标完全不动 | 光学高度太高 | 减薄垫片 |
| 光标慢移正常快移飘 | 光学高度偏低 / 桌面反光 | 加 0.5mm 垫片；换鼠标垫 |
| 光标静止漂移 | 漏光/桌面反光 | 四周遮光；哑光垫 |
| 语音延迟大 | 网络 / 未做流式分句 | 检查分句缓冲；换更近的服务区 |
| 语音完全无响应 | 云端 Key 失效 / 未联网 | 看 `on_event` 的 error code |
| 顶壳烫手（>45°C） | 散热不达标 | 按 S8.6 → S8.7 → S8.8 逐级整改 |
| 重量手感差（>300g） | 铝板过厚 / 壁厚过大 | 铝板改 1.2mm；壁厚 3.0→2.4；加内部减重槽 |
| Android 息屏后不响应 | ROM 杀后台 | 按引导页加白名单 |
