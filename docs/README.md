# AD 项目文档索引

AD（Advanced Desktop）= **鼠标形态的无屏微型计算机**。板载麦克风与扬声器，语音进、语音出；自身位移驱动光标。**屏幕是可选外设**：要么 BBB 原生 HDMI 直出，要么由 Android 载体把 AD 自己的画面投到 PC 显示器上。硬件走 L1 开源路线（BeagleBone Black），软件是一份 Rust 核心 + 两个渲染器 + 一个 PC 端 Receiver。

> 当前版本：**v4.0**（2026-11-06）
> 状态：决策已闭环（D1–D5），概念模型已修正（AD ≠ 桌面软件）。**未采购、未下单、未改动任何站点。**

## 版本规则

1. **不覆盖旧版本**：每次大改新建目录（v4…），旧版原样保留。
2. **每次改动必须进 CHANGELOG**：按「变更点 / 原因 / 影响」三列，不接受无记录的修改。
3. **改设计前先改 DECISIONS**：决策记录是上游，设计文档是下游。
4. **不确定项一律标注**：`【实测】` `【询价】` `【需核实】`，禁止估造。
