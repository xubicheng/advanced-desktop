## 说明

- 所有价格为**区间估算**，不是报价；标注「需询价」的品类波动大；
- **未下单、未询价、未访问任何购物站点**；
- 不提供店铺链接（易失效，且不做背书）；
- 详细理由与避坑见 [docs/v3/采购清单-淘宝优先.md](../docs/v3/采购清单-淘宝优先.md)。
